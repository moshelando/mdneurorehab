NEURO-REHAB REFERENCE PROTOTYPE 3.0-R1

This corrected package is fully self-contained.

Every HTML page includes its own complete CSS and JavaScript. The pages do not depend on Version 2.0 or on the assets folder for formatting or interaction. The assets folder is retained only as an editable source copy.

For GitHub Pages:
1. Delete the current site files from the repository, but keep the repository itself.
2. Upload every file and folder inside this package to the repository root.
3. Confirm that index.html is at the root.
4. Keep Pages configured to main / (root).
5. Wait for the GitHub Pages deployment action to complete, then hard-refresh the page with Ctrl+F5.
