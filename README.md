# Maryland Neuro-Rehab Reference Website — Prototype 3.0

Prototype 3.0 is an interactive proposal and decision tool for the possible new Maryland Neuro-Rehab website. It is not a live clinical website and contains no working patient-data system.

## Start here

1. Open `review/index.html` to understand what the prototype contains.
2. Open `review/decisions.html` for the exact decisions that must be answered.
3. Open `index.html` to browse the proposed public website.
4. Use **Hide review notes** to switch between annotated review mode and a cleaner visitor preview.

## What changed in 3.0

- Clearly separates the proposed public website from prototype commentary.
- Adds a persistent annotated/clean viewing toggle.
- Adds a page-specific guide explaining what each page proposes, asks, and still needs.
- Rewrites the Start Here guide around three distinct content types.
- Adds a dedicated decision list for meetings and approvals.
- Clarifies the difference between programs, disciplines, conditions, techniques, and goals.
- Replaces ambiguous labels with explicit terms such as Physical Therapy, Occupational Therapy, and Speech-Language Therapy.
- Keeps placeholders where facts are unknown, but identifies exactly what belongs there.

## Important limitations

- Forms are demonstrations only and transmit or store nothing.
- Medical, staffing, insurance, legal, and operational information is not approved.
- `noindex` is requested, but a GitHub Pages site is still publicly accessible to anyone with the URL.
- Do not add patient information, confidential records, passwords, or private business material.
