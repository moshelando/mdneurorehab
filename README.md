# Maryland Neuro-Rehab Proposed Website Prototype 4.1

This is a simplified, self-contained reference prototype for the proposed Maryland Neuro-Rehab website.

## Purpose

The site presents the proposed information architecture, visual system, page templates, and representative working copy. Where final clinical, operational, staff, insurance, legal, or branding information is not yet known, the page contains a clear placeholder or approval label.

There are no separate review pages, checklists, review drawers, or reviewer controls. The prototype is intended to be browsed as a proposed website.

## Running locally

Open `index.html`, or run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## GitHub Pages

Upload the contents of this folder to the repository root and publish from the `main` branch `/ (root)`. The site uses relative links and is compatible with project-site paths.

## Important

This is planning material. Do not use the demo forms to collect real patient or health information. All medical, legal, insurance, staff, and operational statements require appropriate approval before production use.
