# Maryland Neuro-Rehab Reference Prototype 3.0-R2

This release restores the full Prototype 2.0 visual system and adds a separate, clearer review layer.

- The normal pages are the proposed public website.
- The **Review this page** drawer contains planning questions and missing information.
- **View clean site** hides prototype-only elements.
- Every HTML page includes its complete CSS and JavaScript inline.
- The `assets` directory is also included for maintainability, but the HTML pages do not depend on it.

This is a planning prototype, not a live clinical website.
