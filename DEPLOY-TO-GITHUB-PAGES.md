# Publish Prototype 2.0 with GitHub Pages

This folder is ready to publish as a static GitHub Pages project site. It includes `.nojekyll`, `robots.txt`, and page-level `noindex` metadata.

## Important

The site remains publicly accessible to anyone with the URL. Do not add patient information, confidential business information, private clinical records, or unapproved personal data.

## Files to upload

Upload the **contents of this folder** so that `index.html`, `assets`, `programs`, `services`, and the other folders appear at the top level of the repository. Do not upload only the ZIP file.

## Publishing summary

1. Create a GitHub repository.
2. Upload all files and folders from this directory.
3. Commit the upload.
4. Open repository **Settings → Pages**.
5. Set the source to **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Save and open the published URL shown by GitHub.

See the accompanying chat instructions for the exact current GitHub interface steps.
